# RoboArm X2 Firmware Release Notes

## Version 2.3 (2026-06-02)
- New "teach mode" lets operators record waypoints by moving the arm by hand.
- Collision detection sensitivity can now be configured between 80 N and 150 N.
- Fixed a bug where the status LED stayed orange after a successful reset.

## Version 2.2 (2026-02-14)
- Added support for ROS 2 Jazzy in the open-source driver.
- The web dashboard now shows joint temperatures in real time.
- Firmware update time reduced from 12 minutes to about 8 minutes.

## Version 2.1 (2025-10-30)
- Python SDK 2.x released; the legacy Python 1.x SDK is deprecated and will stop receiving updates in 2027.
- Added Modbus TCP support for PLC integration.

## Version 2.0 (2025-07-01)
- First release for the X2 hardware. Maximum speed raised to 1.2 m/s at the tool flange.
