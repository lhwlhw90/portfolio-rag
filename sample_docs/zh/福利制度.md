# 星河科技员工福利制度

## 社会保险与公积金
公司按照国家规定为员工缴纳五险一金，住房公积金缴存比例为12%。
员工入职当月起即可参加补充商业医疗保险，覆盖门诊和住院费用，子女可以按半价加入。

## 体检
每位员工每年享有一次免费体检，年满40岁的员工可以选择高级体检套餐。

## 节日与生日福利
春节、端午节和中秋节公司会发放节日礼品。
员工生日当月可以领取200元生日礼金。

## 健身与交通
公司每月提供150元健身补贴，需凭健身房发票报销。
晚上9点以后下班的员工可以报销打车费用。

## 其他福利
员工推荐的候选人入职并通过试用期后，推荐人可获得5000元推荐奖金。
入职满五年的员工每年额外增加3天年假。
